# 서식도우미

한글·엑셀·파워포인트·에듀파인 기안기에서 글꼴, 공문 서식, 표, 수식, 디자인을 단추 한 번으로 적용하는 떠 있는 패널 도구입니다.

## 받기
- 오른쪽 **Releases** 에서 가장 새 `SeosikDoumi-v….zip` 을 내려받아 압축을 풉니다.
- `서식도우미` 폴더를 **바탕 화면이나 문서 폴더**에 두고 `서식도우미.exe` 를 실행합니다. (`_internal` 폴더는 지우지 마세요)
- 자세한 사용법은 폴더 안 `서식도우미 사용설명서.html` 을 여세요.

## 업데이트
- v2.2부터는 새 버전이 나오면 패널 아래에 **[지금 업데이트]** 알림이 뜹니다. 누르면 잠깐 꺼졌다 새 버전으로 켜집니다.
- 직접 확인하려면 패널 위쪽 버전 글자(⟳)를 누르세요. 내 설정(글자 묶음·내 틀·내 그림)은 그대로 남습니다.
- 인터넷이 안 되는 PC에서는 여기서 새 압축 파일을 받아 덮어쓰세요.
